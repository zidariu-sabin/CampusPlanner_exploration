# Campus Planner Design Mockup

Standalone visual mockup project for iterating the Campus Planner redesign.

## Scope

- Mocked data only.
- No API integration.
- No authentication.
- No persistence.
- Focused on design and workflow shape.

## Screens

1. Dashboard
2. Campus And Building Configuration
3. Space configuration
4. Room Booking
5. Organization settings

## Run

```bash
npm install
npm run dev
```

# Campus Planner Design Mockup

Standalone visual mockup project for iterating the Campus Planner redesign.

## Scope

- Mocked data only.
- No API integration.
- No authentication.
- No persistence.
- Focused on design and workflow shape.

## Screens

1. Organization Dashboard
2. Campus And Building Configuration
3. Floor Import Pipeline
4. Room Booking
5. Admin Settings

## Run

```bash
npm install
npm run dev
```

# Admin Campus Configuration

## Goal
Let admins define campus footprint and spaces.

## User Flow
1. Admin defines campus origin and GeoJSON footprint.
2. Admin aligns cadastral image.
3. Admin defines buildings, outdoor resources, and POIs.

## Acceptance Criteria
- Campus setup steps are visible.
- Spaces setup can be opened from campus setup.
- GeoJSON footprint and selected space footprint are represented.

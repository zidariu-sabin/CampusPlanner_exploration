# Admin Space Configuration

## Goal
Let admins configure a floor plan into bookable rooms.

## User Flow
1. Admin selects campus space and floor.
2. Admin uploads and aligns floor plan image.
3. Admin defines rooms and labels.
4. Admin reviews warnings.
5. Admin publishes the configured space.

## Acceptance Criteria
- Import pipeline steps are visible.
- Room warnings are shown before publish.
- Publish state is distinct from draft/review states.

# Booking Detail

## Goal
Show the confirmed meeting, room location, participants, and route guidance.

## User Flow
1. User opens a meeting from dashboard or sidebar.
2. User sees confirmation status and room metadata.
3. User reviews route steps.
4. User starts navigation.

## Content
- Meeting title and time.
- Room, floor, organizer, and guests.
- Indoor route map.
- Step-by-step route instructions.

## Acceptance Criteria
- Confirmed status is visible.
- Location includes building, room, and floor.
- Start navigation action is clear.

# Member Dashboard

## Goal
Give a normal member a concise overview of planned meetings and next navigation action.

## User Flow
1. User opens the member dashboard.
2. User sees today's meetings and where each meeting is located.
3. User clicks a meeting to open the booking detail page.
4. User clicks Open map view to inspect the campus map.

## Content
- Today's meeting count.
- Weekly meeting count.
- User-owned booking count.
- Next meeting countdown.
- Planned meetings with time, title, location, and details.

## Acceptance Criteria
- Meeting rows are clickable.
- Clicking a meeting opens Booking Detail.
- Open map view opens Member Map View.

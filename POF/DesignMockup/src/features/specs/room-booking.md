# Room Booking

## Goal
Allow a user to create a meeting in an available campus room.

## User Flow
1. User enters meeting title and participants.
2. User compares available rooms.
3. User selects a room.
4. User selects an available time slot.
5. User confirms the booking.

## Content
- Candidate rooms with availability, capacity, equipment, and walk distance.
- Slot selector with free, busy, and selected states.
- Booking summary for selected room.

## Acceptance Criteria
- Busy slots are visually distinct.
- Selected room is clearly marked.
- Confirm booking is visible after room and slot are shown.
